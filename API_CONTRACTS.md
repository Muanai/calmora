# Calmora API Contract & Technical Documentation

Version: 1.0.0  
Base URL: `/api/v1`  
Protocol: HTTPS / JSON & Server-Sent Events (SSE)


## Overview

Calmora is an AI-powered mental health companion providing instant, clinical-intimidation-free first aid grounding and overthinking management for Gen-Z students experiencing severe anxiety and agoraphobia.

This document serves as the official API contract between the Frontend (Mobile/PWA) and Backend (FastAPI Microservices) teams.

## API Endpoints

### 1. AI Companion & RAG Pipeline

#### `POST /api/v1/chat/stream`

Initiates a real-time conversational streaming session with the Calmora AI Companion. Employs Retrieval-Augmented Generation (RAG) referencing validated CBT and grounding manuals.

* **Request Body:**

```json
{
  "user_id": "usr_9f8b1c2a-3e4d-5f6a-7b8c-9d0e1f2a3b4c",
  "message": "I feel extremely anxious and unable to step outside my room today.",
  "intensity_level": "high"
}

```

* **Field Specifications:**
* `user_id` (string, required): Unique identifier for the user.
* `message` (string, required): User prompt or emotional statement.
* `intensity_level` (string, required): Self-reported or inferred distress level (`low`, `medium`, `high`, `crisis`).


* **Response:**
* **Content-Type:** `text/event-stream` or `application/x-ndjson`
* **Body:** Streaming text tokens generated by LLM pipeline.

### 2. P3K Grounding & Shadow Point System

#### `POST /api/v1/actions/grounding`

Logs completed grounding exercises (e.g., Penenang Cepat, Misi Langkah Mikro) and triggers async calculations for the internal Shadow Point System. Backend enforces daily rate limits per `action_type` (see BL4).

* **Request Body:**

```json
{
  "user_id": "usr_9f8b1c2a-3e4d-5f6a-7b8c-9d0e1f2a3b4c",
  "action_type": "quick_calm",
  "duration_seconds": 120,
  "completed": true
}

```

* **Field Specifications:**
* `user_id` (string, required): Unique user ID.
* `action_type` (string, required): Type of exercise (`quick_calm`, `micro_step_lv1`, `micro_step_lv2`, `micro_step_lv3`).
* `duration_seconds` (integer, required): Time spent on exercise in seconds.
* `completed` (boolean, required): Status of exercise completion.


* **Response:** `200 OK`

```json
{
  "status": "success",
  "message": "Action logged successfully and points accumulated in backend."
}

```

### 3. Journaling & Privacy Control

#### `POST /api/v1/journal/entry`

Stores encrypted user journal entries. Submitting a journal entry also triggers Shadow Point calculation (`journal` = +20 points, max 2x/day per BL4).

* **Request Body:**

```json
{
  "user_id": "usr_9f8b1c2a-3e4d-5f6a-7b8c-9d0e1f2a3b4c",
  "encrypted_content": "U2FsdGVkX1+vN2...",
  "mood_tag": "overthinking"
}

```

* **Response:** `201 Created`

```json
{
  "status": "success",
  "journal_id": "jrn_7a8b9c0d-1e2f-3a4b-5c6d-7e8f9a0b1c2d"
}

```

#### `DELETE /api/v1/privacy/burn/{user_id}`

Executes immediate cascade deletion of all user data (Burn Button protocol) across databases and vector storage.

* **Path Parameters:**
* `user_id` (string, required): Target user ID for eradication.


* **Response:** `200 OK`

```json
{
  "status": "burnt",
  "message": "All traces eradicated successfully."
}

```

### 4. Pay-It-Forward Ecosystem

#### `POST /api/v1/sponsor/donate`

Processes Hero Package payments from donors and automatically grants Premium access to the top user in the backend Waiting List.

* **Request Body:**

```json
{
  "donor_id": "usr_1a2b3c4d-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "amount": 49000,
  "premium_months_granted": 1
}

```

* **Response:** `200 OK`

```json
{
  "status": "success",
  "sponsored_user_id": "usr_9f8b1c2a-3e4d-5f6a-7b8c-9d0e1f2a3b4c"
}

```

#### `GET /api/v1/sponsor/status/{user_id}`

Retrieves the user's current subscription status and sponsorship origin.

* **Path Parameters:**
* `user_id` (string, required): User ID to check.


* **Response:** `200 OK`

```json
{
  "account_type": "premium",
  "sponsored_by": "anonymous"
}

```

## Error Handling Standards

All endpoints return standard HTTP status codes and structured error payloads:

```json
{
  "error": {
    "code": "INVALID_INPUT",
    "message": "The field 'duration_seconds' must be a positive integer.",
    "details": []
  }
}

```

Common status codes:

* `200 OK`: Successful operation.
* `201 Created`: Resource successfully created.
* `400 Bad Request`: Validation failure.
* `401 Unauthorized`: Missing or invalid JWT.
* `404 Not Found`: Resource or user does not exist.
* `500 Internal Server Error`: Unhandled server exception.
